长视频与训练蓝图

服务于超长工作流 P2（长视频拼接）与 P5（LoRA 微调）。三处来源：ComfyUI-H3-LongTake（开源实现）、vibewarp Qwen 时序 LoRA 训练文档、ComfyDeploy（已开源平台）。

一、H3-LongTake：重叠续写（P2 照抄）

核心公式

L = clip_frames（17k+5） C = context_frames（重叠帧） clip 0 : source [0, L) → 全部输出 clip i : source [i·(L−C), i·(L−C)+L)，anchor = 上一段尾部 → 前 C 帧裁掉

二、Qwen 时序 LoRA 训练（P5 参考）

  • 一键装环境：bash scripts/setup_qwen_temporal_training.sh
  • 数据编译：tools/prepare_qwen_temporal_dataset.py（--resume 断点续跑）
  • 租长训练窗之前先验证数据集：tools/validate_qwen_temporal_dataset.py
